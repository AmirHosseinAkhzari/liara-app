# Vazirmatn

Vazirmatn-Regular.ttf and Vazirmatn-Bold.ttf are by Saber Rastikerdar and
contributors (https://github.com/rastikerdar/vazirmatn), licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org). They are embedded in
the Persian HTML reports this plugin writes.

Liara's own typeface (Yekan) is commercial, so reports list it first and fall
back to Vazirmatn when it is not installed.
